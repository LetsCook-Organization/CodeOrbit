# Screenshots

Real screenshots of CodeOrbit for the main README (issue [#12](https://github.com/LetsCook-Organization/CodeOrbit/issues/12)) and for talks or posts.

## What to capture

Open the live app at <https://letscook-organization.github.io/CodeOrbit/>. On a first visit, press **Try it with sample data first** (or go to **Settings → Your data → Load sample data**) so every screen has data. Never capture your own data.

| File name | Page | Size | What should be visible |
| :--- | :--- | :--- | :--- |
| `home.png` | **Home** (`#dashboard`) | Desktop, 1440 × 900 | Greeting, hours this week against the goal, the orbit of skills, hours for each day, "Coming up" |
| `home-phone.png` | **Home** on a phone | 390 × 844 | The same page in the phone layout |
| `first-visit.png` | **First visit** | Desktop, 1440 × 900 | The "No skills added yet" screen. Use a private/incognito window so nothing is saved yet |
| `skills.png` | **Skills** (`#skills`) | Desktop, 1440 × 900 | Skill cards with percentages and the category filters |
| `progress.png` | **Progress** (`#analytics`) | Desktop, 1440 × 900 | The progress score and the charts |

You do not need all of them: the README needs 2–4.

## Rules

- **Format:** `.png` or `.webp`, compressed to under 300 KB each (for example with <https://squoosh.app>).
- **Browser zoom:** 100%. Close other pop-ups and messages before capturing.
- **Alt text:** every image in the README needs `alt` text that says what the screenshot shows, for example `alt="CodeOrbit Home: 6.5 of 12 hours studied this week, and six skills shown as planets"`.
